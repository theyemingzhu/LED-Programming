# Studio Mapper and recording updates

Mapper is reached from Layout's **Mapper** action. It reuses the retained Mapper editor and isolated authored-frame engine in a separate workspace. Its Save/Load files remain `lightweaver.mapper-project`; authored effects, scenes and external exports remain in that format. The Studio handoff explicitly reviews and copies sampled geometry, offsets and direction, not effect code. Existing artwork is retained; a different artwork source requires a new Studio project. No firmware flasher or WLED connection control is exposed in the embedded workspace. Card-local Studio retains its existing surface.

Saved recording rows report source freshness separately from frozen playback validity. The check compares the linked saved Lab recipe (asset ID plus media lineage) or owning Flow scene, and the current full physical bake hash, including artwork, wiring, rendering settings and side choice. It does not use the unrelated selected look. A missing editable source or incomplete inputs are explicitly unknown; retained recipe/scene snapshots remain available for explicit recording where current geometry is ready. Current means matching saved inputs, not a new hardware or renderer-version acceptance.

**Record again** exists in Lab's visible Saved recordings section. It is the only new rendering trigger. It prepares a snapshot, renders and verifies through the existing recording pipelines, stores/read-verifies content-addressed media, and changes the project asset only after success. Navigation cancels the operation; changed source/project context refuses the result. A failure retains the original asset and media. Successful replacement retains the asset ID and playlist references, while old content-addressed bytes remain retrievable. No card mutation, automatic rebake, LWSEQ/sidecar format change or playback compatibility change is introduced.

The Mapper HTML entry is included in public builds and offline shell caching. Dependency deduplication allows a Studio-only dependency installation to build it. Mapper is excluded from card-local build routing; there is no new firmware release or device write in this change.
